📖 项目概览

MarkItDown 是由 Microsoft AutoGen 团队开发的轻量级 Python 工具，用于将各种文件格式转换为 Markdown，专为 LLM 和文本分析流水线设计。

与 textract 类似，但重点在于保留文档的重要结构和内容（标题、列表、表格、链接等），以 Markdown 形式输出，对 LLM 极其友好且高效省 Token。

转换流程

输入源 → MarkItDown → Converter → Markdown 输出

支持：本地文件 · URL · 二进制流 · requests.Response · Data URI · File URI

💻 命令行使用

基本用法

# 转换文件并输出到标准输出
markitdown path-to-file.pdf

# 指定输出文件
markitdown path-to-file.pdf -o document.md

# 管道方式
cat path-to-file.pdf | markitdown

# 重定向输入
markitdown < path-to-file.pdf

完整参数一览

参数说明
-v, --version显示版本号
-o, --output输出文件名（不指定则输出到 stdout）
-x, --extension提供文件扩展名提示（如从 stdin 读取时）
-m, --mime-type提供 MIME 类型提示
-c, --charset提供字符编码提示（如 UTF-8）
-d, --use-docintel使用 Azure 文档智能（需配合 -e）
--use-cu使用 Azure 内容理解（需配合 --cu-endpoint）
-e, --endpointAzure 文档智能 Endpoint
--cu-endpointAzure 内容理解 Endpoint
--cu-analyzer内容理解分析器 ID（不指定则自动选择）
--cu-file-types限制路由到 CU 的文件类型（逗号分隔）
-p, --use-plugins启用第三方插件
--list-plugins列出已安装的第三方插件
--keep-data-uris保留 data URI（如 base64 图片），默认截断

常用示例

# 转换 Word 文档

🐍 Python API

基本用法

from markitdown import MarkItDown

md = MarkItDown()
result = md.convert("test.xlsx")
print(result.markdown)          # Markdown 文本
print(result.title)             # 文档标题（可选）
print(result.text_content)      # markdown 的别名（软弃用）

多种输入源

from markitdown import MarkItDown

md = MarkItDown()

# 本地文件
result = md.convert_local("report.pdf")

# URL
result = md.convert_uri("https://example.com/page.html")

# 二进制流
with open("data.docx", "rb") as f:
    result = md.convert_stream(f)

# requests.Response
import requests
resp = requests.get("https://example.com/file.pdf")
result = md.convert_response(resp)

# 通用 convert() 自动识别类型
result = md.convert("path/to/file.pdf")        # 本地文件
result = md.convert("https://example.com")      # URL
result = md.convert(Path("/path/to/file.pdf"))   # Path 对象

    def convert(self, file_stream: BinaryIO, stream_info: StreamInfo, **kwargs) -> DocumentConverterResult:
        # 实现转换逻辑
        ...

2. 在包中导出插件接口：

# 插件接口版本（目前仅支持 1）
__plugin_interface_version__ = 1

def register_converters(markitdown: MarkItDown, **kwargs):

🔍 OCR 插件 (markitdown-ocr)

简介

通过 LLM Vision 从 PDF、DOCX、PPTX、XLSX 中嵌入的图片提取文字。无需额外 ML 库或二进制依赖。

安装

pip install markitdown-ocr
pip install openai  # 或任何 OpenAI 兼容客户端

使用方式

from markitdown import MarkItDown
from openai import OpenAI

md = MarkItDown(
    enable_plugins=True,
    llm_client=OpenAI(),
    llm_model="gpt-4o",
)
result = md.convert("document_with_images.pdf")
print(result.markdown)
如果未提供 llm_client，插件仍然会加载，但 OCR 功能将被静默跳过，回退到标准内置转换器。

支持的转换增强

PDF

  • 按位置提取嵌入图片并 OCR
  • 扫描件自动检测整页 OCR
  • 损坏 PDF 使用 PyMuPDF 回退

DOCX / PPTX / XLSX

  • DOCX：图片 OCR 内联插入
  • PPTX：支持组合内图片
  • XLSX：按工作表列出图片

OCR 输出格式

*[Image OCR]
<提取的文字内容>
[End OCR]*

🤖 MCP 服务器 (markitdown-mcp)

简介

提供轻量级 STDIO / Streamable HTTP / SSE MCP 服务器，暴露一个工具：convert_to_markdown(uri)

支持 http:、https:、file:、data: URI。

安装与启动

pip install markitdown-mcp

# STDIO 模式（默认）

# Streamable HTTP + SSE 模式

参数说明

--sse（已弃用）同 --http
--host绑定主机（默认 127.0.0.1）

转换器优先级机制

转换器按优先级排序，数值越低越优先尝试：

优先级类型示例
-1.0插件转换器OCR 增强转换器
0.0特定格式转换器PdfConverter, DocxConverter
10.0通用格式转换器PlainTextConverter, HtmlConverter
后注册的转换器优先级更高。Azure 转换器（如已配置）会被注册到栈顶，优先于所有内置转换器。

使用 magika 库进行智能文件类型检测，结合扩展名、MIME 类型、URL 等多种提示综合判断。

输入流 → StreamInfo 收集 → magika 检测 → 多猜测列表 → 逐个尝试 Converter

🔒 安全注意事项
重要：MarkItDown 以当前进程权限执行 I/O 操作。与 open() 或 requests.get() 一样，它可以访问进程能访问的所有资源。在不受信任的环境中，务必对输入进行清洗。

安全最佳实践

  • 清洗输入：不要将不受信任的输入直接传递给 MarkItDown，需先验证和限制
  • 使用最窄的 API：
    • 仅需本地文件？用 convert_local()
    • 需要控制 URI 获取？自己调用 requests.get() 再传 convert_response()
    • 最大控制？打开流后用 convert_stream()
  • MCP 服务器安全：默认绑定 localhost，无身份验证，不要绑定到公网接口
  • 限制访问：包括限制文件路径、限制 URI 方案和网络目标、阻止访问私有/回环/元数据地址
